# Catálogo de Componentes Visuales (`src/components`)

Componentes organizados por zona y responsabilidad para evitar colisión de interfaces:

- `ui/`: Componentes atómicos base (botones, inputs, modales, alertas, badges).
- `superadmin/`: Componentes exclusivos para la consola global (diseño en negro y rojo, inspirado en Amazon).
- `customer/`: Componentes para el portal de clientes SaaS (facturación, suscripciones, licencias).
- `tenant/`: Componentes para la administración privada de tenants (`/admin`).
- `public/`: Componentes para los escaparates públicos de las tiendas.
