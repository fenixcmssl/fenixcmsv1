# Arquitectura de Temas de FenixCMS (`src/themes`)

Este directorio aloja el catálogo de plantillas y temas visuales para las tiendas y escaparates de los tenants.

## Capacidades
- **Independencia Visual:** Cada tenant puede seleccionar y configurar su tema sin alterar la lógica de negocio ni el backend.
- **Configuración por Tenant:** Selección de paleta de colores, tipografías, encabezados, banners y componentes de escaparate.
- **Sobreescritura Segura:** Sistema de plantillas que permite personalizar vistas preservando la seguridad y compatibilidad de actualizaciones.
